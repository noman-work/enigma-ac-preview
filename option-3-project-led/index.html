Air Conditioning for Commercial Spaces

Glazing, computers, kitchens and busy rooms all add heat.

A room that runs too warm is harder to work in, less comfortable for customers and harder on equipment. We work out the heat load, layout and use of each area, then install a system that fits, with neat refrigerant pipework, proper condensate drainage and full commissioning.

We work in schools, nurseries, offices, restaurants, commercial kitchens, server rooms and larger multi-zone buildings.

VRF Air Conditioning Installation

VRF (Variable Refrigerant Flow) runs many indoor units from shared outdoor units and sends each room only the refrigerant it needs. It suits multi-floor offices, schools with lots of rooms, hotels and larger shops. With some systems, one room can heat while another cools.

We position the outdoor units, run the branch pipework, fit cassette, ducted or wall-mounted indoor units, then pressure test, evacuate and commission the system.

Comfortable Cooling for Your Home

A top-floor flat or a south-facing bedroom can be hard to use on a hot day. A quiet wall-mounted unit, sized for the room, lets you set the temperature you want. We check the room, the outside wall and the pipe route first.

  • Flats and apartments Split systems where there’s a place for the outdoor unit.
  • Bedrooms and baby rooms We talk you through unit position, noise and controls.
  • Several rooms Multi-split: several indoor units on 1 outdoor unit.
